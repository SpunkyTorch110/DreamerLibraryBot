
This open source project represents the codebase for the DREAMER Library Bot on Discord. This is a private bot created and programmed by me as a hobby to serve as a collectible card game for my D&D Adventures. 

With this bot you can roll various characters existent in the database and freely trade them, sell them or simply collect them and show off your collection. In the future there will be more features like an auto battler, mini-games, trade market and etc...

This bot is in development so don't expect much for a while.

**Requirements**

- Python 3.12
- SQLite Database
- Discord.py
- Dotenv
